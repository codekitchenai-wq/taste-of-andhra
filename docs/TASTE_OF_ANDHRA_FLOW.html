Architecture details

Frontend React 19, TypeScript, Vite, Tailwind CSS v4, React Router. Single-page app deployed on Vercel.
Backend Supabase PostgreSQL with Row Level Security. No custom Express server — all data access goes through typed service functions in src/services/.
Authentication Customers: mobile + SMS OTP. Admins: email + password. Roles stored in profiles table (customer, admin, delivery).
Storage Dish and category images uploaded to Supabase Storage bucket restaurant-images. Static marketing images served from /public/images.

Checkout details

  • Address: Select saved address or add new one at checkout.
  • Coupon: Apply active offer code — discount validated against minimum order value.
  • Pricing: Subtotal + 5% tax + delivery (₹49, free above ₹399) − discount = total.
  • COD: Order created with payment_status: pending, cart cleared on success.
  • Online: Order created first, then Razorpay modal (or demo auto-pay if no API key). Cart kept until payment succeeds.
  • Cancel: Customer can cancel while status is pending or confirmed.

Order status lifecycle

pending → confirmed → preparing → ready → out_for_delivery → delivered  |  cancelled

Status stepper shown on order details page. Admin updates status from Orders or Delivery pages.

Auth details

  • Phone numbers stored as E.164 format (+91XXXXXXXXXX) in Supabase Auth.
  • Registration collects full name + phone; login uses phone only.
  • On first verify, handle_new_user trigger inserts row into profiles.
  • Deactivated accounts (is_active = false) are signed out automatically.
  • Cart, addresses, and orders are tied to authenticated user via RLS policies.
