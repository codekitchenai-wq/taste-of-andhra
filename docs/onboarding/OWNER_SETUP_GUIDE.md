# Owner setup guide (short)

**Time needed:** about 15–30 minutes for first setup.

## What we need from you

1. **Restaurant setup sheet** — address, GST, FSSAI, hours, UPI, delivery pincodes  
   → Edit only the **value** column in `RESTAURANT_SETUP_TEMPLATE.csv`. Leave defaults if they are fine.
2. **Menu list** — Excel/CSV with one row per dish  
   → Download / copy `MENU_IMPORT_TEMPLATE.csv` and replace sample rows with your menu.
3. **Logo** (optional) — square image, PNG or JPG.

A PDF menu alone is OK as a **reference**, but the spreadsheet is what we load (fewer mistakes on prices).

## How to fill the menu sheet

- One dish = one row  
- `price` = number only (`199`, not `Rs 199` or `₹199`)  
- `is_veg` = `TRUE` or `FALSE`  
- `spice_level` = `mild`, `medium`, `hot`, or `extra_hot` (or leave blank)  
- Use clear `category` names (Starters, Biryani, Beverages, …)  
- Skip photos for now

## What happens after you send it

1. We create your restaurant on the platform  
2. We load the setup sheet + menu  
3. You get Admin login  
4. You check dishes and prices; add photos if you want  
5. Place one test order with us  
6. Go live  

## After you are live

Use **Admin → Categories / Dishes / Settings** for everyday changes.  
You do **not** need to send a new spreadsheet for small updates.

## Need help?

Message us on WhatsApp with your restaurant name. Attach the setup + menu files in one message if you can.
